Device configuration for the POCO F3 / Redmi K40 (alioth)
=========================================================

The POCO F3 (codenamed _alioth_) is a phone from Xiaomi.

It was released in March 2021.

## Device specifications

Basic   | Spec Sheet
-------:|:-------------------------
SoC     | Qualcomm SM8250-AC Snapdragon 870 5G (7 nm)
CPU     | Octa-core (1x3.2 GHz Kryo 585 & 3x2.42 GHz Kryo 585 & 4x1.80 GHz Kryo 585)
GPU     | Adreno 650
Memory  | 128GB 6GB RAM, 256GB 8GB RAM
Shipped Android Version | Android 11, MIUI 12
Battery | Li-Po 4520 mAh, non-removable
Display | AMOLED, 120Hz, HDR10+, 1080 x 2400 pixels
